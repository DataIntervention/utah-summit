### GitHub Pages deployment
1. Create new public repo at github.com
2. Upload all 4 files: index.html, manifest.json, icon.svg, README.md
3. Settings → Pages → Deploy from main branch → Save
4. Your URL: https://YOUR-USERNAME.github.io/REPO-NAME

### Add to iPad Home Screen
1. Open your URL in Safari
2. Tap the Share button (box with arrow pointing up)
3. Scroll down → Add to Home Screen
4. Tap Add
